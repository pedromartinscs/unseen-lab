# Roadmap

This roadmap describes direction, not a release commitment.

## v0.1 — Foundation

- [x] Shared Pillow/NumPy core.
- [x] Gaussian noise.
- [x] Gaussian blur.
- [x] Micro-resampling.
- [x] Optional JPEG round-trip.
- [x] MAE, RMSE, and PSNR.
- [x] CLI.
- [x] Standalone Qt editor shell.
- [x] Initial GIMP 3 Python adapter.
- [x] Core tests.
- [ ] Manual GIMP validation on Windows.

## v0.2 — Editor usability

- [ ] Zoom and 1:1 mode.
- [ ] Pan / fit-to-window.
- [ ] Split-view comparison.
- [ ] Drag-and-drop open.
- [ ] Recent files.
- [ ] Per-transform enable switches.
- [ ] Recipe/preset serialization.
- [ ] Better progress and error surfaces.

## v0.3 — Analysis

- [ ] SSIM.
- [ ] Difference map.
- [ ] Histogram comparison.
- [ ] Channel-level metrics.
- [ ] Optional perceptual similarity.
- [ ] Parameter-budget exploration.

## v0.4 — More transforms

- [ ] Poisson noise.
- [ ] Speckle noise.
- [ ] Chroma-only perturbation.
- [ ] Luminance-only perturbation.
- [ ] Small affine transforms.
- [ ] Color-space round trips.
- [ ] Controlled quantization.
- [ ] Format-specific export experiments.

## v0.5 — GIMP integration

- [ ] Recipe-driven GIMP procedure.
- [ ] Improved procedure UI.
- [ ] Installation helper.
- [ ] Compatibility matrix across GIMP 3 releases.
- [ ] Evaluate GEGL implementations for non-destructive filters.

## v1.0 — Stable tool

- [ ] Versioned recipe format.
- [ ] Documented transform semantics.
- [ ] Packaged standalone releases.
- [ ] Stable CLI.
- [ ] Tested GIMP installation path.
- [ ] Selected open-source license.
- [ ] Screenshots and release documentation.
